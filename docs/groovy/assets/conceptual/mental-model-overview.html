Key mental model concepts
Formulas run in Java
Use Java methods: Math.sqrt()
Not Python: math.sqrt() ✗
Processed in batches, not rows
The engine JIT-compiles a formula once, then reuses it across chunks — the first run of a query is often slower than the next.
Tables are immutable
Operations create new tables
Old tables unchanged
Always: result = t.where(...)
Safe to share across threads, and the engine can reuse unchanged data instead of recomputing it.
Order is not guaranteed
Rows process in parallel
Don't use counters in formulas
Use ii for row position
Aggregations and joins can reorder rows for performance — sort explicitly if display order matters.
Static vs live tables
Static: from files, snapshots
Live: from streams, time_table
Same code works for both
A live table's operations are recorded once and replayed automatically as new rows arrive.
