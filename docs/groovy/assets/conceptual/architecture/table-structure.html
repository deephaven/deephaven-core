Table structure: RowSets + ColumnSources

Efficient sharing enables zero-copy operations and reduced memory usage

Same keys
ColumnSource

ColumnSource

→ source.B
  • Column A is stored once in memory, referenced by all three tables
  • RowSet for "renamed" table is shared with "source" (zero-copy view operation)
  • Updates to source.A automatically appear in filtered.A and renamed.A
Key concepts
RowSet
Sparse set of 64-bit row keys
Can be shared or derived (filtered/redirected)
ColumnSource
Column data indexed by row keys
Shared across tables when possible
Shared reference
Points to parent table's data structure
Zero memory overhead for the data itself
Table
Combines RowSet + map of ColumnSources
Lightweight structure, heavy sharing
