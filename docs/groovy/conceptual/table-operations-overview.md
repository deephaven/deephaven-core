A quick reference for table operations

</div>

This page is a quick-reference index of common table operations in Deephaven. Find your task in the table, then follow the link to the operation's reference page for its syntax and examples.

These operations work the same way on [static tables and on real-time tables that tick](./table-types.md). When the source data changes, their results update with it. The one exception in the quick-reference table below is [`rangeJoin`](../reference/table-operations/join/range-join.md), which supports only static tables.

To learn a group of operations by task, see the how-to guides:

- [Select and create columns](../how-to-guides/use-select-view-update.md)
- [Drop, move, and rename columns](../how-to-guides/drop-move-rename-columns.md)
- [Sort table data](../how-to-guides/sort.md)

## Quick reference

| I want to...                                                                           | Use this                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Keep rows matching a condition                                                         | [`where("condition")`](../reference/table-operations/filter/where.md)                                                                                                                                                                                                                                                                                                                     |
| Keep rows whose key values appear, or don't appear, in another table                   | [`whereIn(filterTable, "Key")`](../reference/table-operations/filter/where-in.md) / [`whereNotIn(filterTable, "Key")`](../reference/table-operations/filter/where-not-in.md)                                                                                                                                                                                                              |
| Get the first or last `n` rows                                                         | [`head(n)`](../reference/table-operations/filter/head.md) / [`tail(n)`](../reference/table-operations/filter/tail.md)                                                                                                                                                                                                                                                                     |
| Add columns (stored in memory)                                                         | [`update("NewColumn = formula")`](../reference/table-operations/select/update.md)                                                                                                                                                                                                                                                                                                         |
| Add columns (computed on demand)                                                       | [`updateView("NewColumn = formula")`](../reference/table-operations/select/update-view.md)                                                                                                                                                                                                                                                                                                |
| Keep or compute specific columns (stored in memory), dropping the rest                 | [`select("Column1", "NewColumn = formula")`](../reference/table-operations/select/select.md)                                                                                                                                                                                                                                                                                              |
| Keep or compute specific columns (computed on demand), dropping the rest               | [`view("Column1", "NewColumn = formula")`](../reference/table-operations/select/view.md)                                                                                                                                                                                                                                                                                                  |
| Remove columns                                                                         | [`dropColumns("Column1")`](../reference/table-operations/select/drop-columns.md)                                                                                                                                                                                                                                                                                                          |
| Rename columns                                                                         | [`renameColumns("NewName = OldName")`](../reference/table-operations/select/rename-columns.md)                                                                                                                                                                                                                                                                                            |
| Sort by column                                                                         | [`sort("Column")`](../reference/table-operations/sort/sort.md)                                                                                                                                                                                                                                                                                                                            |
| Sort in descending order                                                               | [`sortDescending("Column")`](../reference/table-operations/sort/sort-descending.md)                                                                                                                                                                                                                                                                                                       |
| Add columns from a lookup table (at most one match per row, null if no match)          | [`naturalJoin(other, "Key", "AddedColumn")`](../reference/table-operations/join/natural-join.md)                                                                                                                                                                                                                                                                                          |
| Add columns from a table where every row must have exactly one match                   | [`exactJoin(other, "Key", "AddedColumn")`](../reference/table-operations/join/exact-join.md)                                                                                                                                                                                                                                                                                              |
| Join every matching row, or cross join with no key                                     | [`join(other, "Key")`](../reference/table-operations/join/join.md)                                                                                                                                                                                                                                                                                                                        |
| Match on a timestamp or other ordered key (closest at or before)                       | [`aj(other, "Key, Timestamp", "AddedColumn")`](../reference/table-operations/join/aj.md)                                                                                                                                                                                                                                                                                                  |
| Match on a timestamp or other ordered key (closest at or after)                        | [`raj(other, "Key, Timestamp", "AddedColumn")`](../reference/table-operations/join/raj.md)                                                                                                                                                                                                                                                                                                |
| Group right-table values that fall in a range ([static](./table-types.md) tables only) | [`rangeJoin(other, ["Key", "Start <= Timestamp <= End"], [AggGroup(...)])`](../reference/table-operations/join/range-join.md)                                                                                                                                                                                                                                                             |
| Apply one aggregation to every non-key column, per group                               | [`sumBy("Key")`](../reference/table-operations/group-and-aggregate/sumBy.md) (also [`avgBy`](../reference/table-operations/group-and-aggregate/avgBy.md), [`maxBy`](../reference/table-operations/group-and-aggregate/maxBy.md), [`minBy`](../reference/table-operations/group-and-aggregate/minBy.md), and similar [dedicated aggregations](../how-to-guides/dedicated-aggregations.md)) |
| Count the rows in each group                                                           | [`countBy("Count", "Key")`](../reference/table-operations/group-and-aggregate/countBy.md)                                                                                                                                                                                                                                                                                                 |
| Apply different aggregations to different columns, per group                           | [`aggBy([AggSum(...)], "Key")`](../reference/table-operations/group-and-aggregate/aggBy.md)                                                                                                                                                                                                                                                                                               |
| Collect each group's values into arrays, or expand arrays back into rows               | [`groupBy("Key")`](../reference/table-operations/group-and-aggregate/groupBy.md) / [`ungroup()`](../reference/table-operations/group-and-aggregate/ungroup.md)                                                                                                                                                                                                                            |
| Compute cumulative or rolling values                                                   | [`updateBy([CumSum(...)], "Key")`](../reference/table-operations/update-by-operations/updateBy.md)                                                                                                                                                                                                                                                                                        |
| Stack tables on top of each other                                                      | [`merge(table1, table2)`](../reference/table-operations/merge/merge.md)                                                                                                                                                                                                                                                                                                                   |

Most entries are methods on a table. [`merge`](../reference/table-operations/merge/merge.md) is a static method. [`AggSum`](../reference/table-operations/group-and-aggregate/AggSum.md) and [`AggGroup`](../reference/table-operations/group-and-aggregate/AggGroup.md), which create [aggregations](./aggregations.md), are static methods too. [`CumSum`](../reference/table-operations/update-by-operations/cum-sum.md), which creates an [update-by operation](../reference/table-operations/update-by-operations/updateBy.md), is a static method too. Deephaven's Groovy sessions import these static methods by default, so your code needs no import statement.

## Diving deeper: API references

For the full interface definitions and operation contracts, see the generated API documentation:

- The [Javadoc for `Table`](/core/javadoc/io/deephaven/engine/table/Table.html) describes the interface and all of its methods.
- The [Javadoc for `TableOperations`](/core/javadoc/io/deephaven/api/TableOperations.html) gives the operation contracts that define behavior.

Each operation's reference page, such as [`where`](../reference/table-operations/filter/where.md) or [`update`](../reference/table-operations/select/update.md), also links to the relevant Javadoc.
